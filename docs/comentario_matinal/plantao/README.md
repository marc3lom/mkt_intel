# Manual do plantão

O Comentário Matinal é escrito e enviado todo dia útil entre 7h00 e 9h00, e a autoria
roda entre os gestores da divisão. Este manual é para quem está de plantão hoje. Ele
não pressupõe que você conheça o repositório — pressupõe que você conheça o mercado.

Leia as páginas na ordem no primeiro dia. Depois disso, o runbook basta.

| Página | Para quê |
|---|---|
| [01 — O primeiro dia](01-primeiro-dia.md) | O que você produz, quem lê, quanto tempo leva, as duas formas de rodar e a janela |
| [02 — Instalação](02-instalacao.md) | Uma vez por máquina, antes do primeiro plantão |
| [03 — Runbook](03-runbook.md) | Os nove passos, do mercado ao e-mail |
| [04 — O que é seu decidir](04-decisoes.md) | Os quatro pontos em que o processo depende de você |
| [05 — Quando dá errado](05-quando-da-errado.md) | O sintoma exato na tela, a causa e a saída |

Quem mexe no código lê o [`README.md`](../README.md) do produto: o que o repositório é,
como está organizado e as decisões de projeto.
